## Девять выживших

Версия 1.0 включает **девять выживших**. Забег начинается с одного персонажа; сигналы SOS позволяют собрать отряд максимум из трёх.

| Выживший | Подтверждённая информация |
| --- | --- |
| SWAT | Точные навыки и бонус лидера: не подтверждено. |
| Tank | Прочный боец; использует Minigun и Rocket Launcher. |
| Engineer | Точные навыки: не подтверждено. |
| Huntress | Дальний бой, критические удары и давление на боссов. |
| Ghost | Боец ближнего боя; точные значения: не подтверждено. |
| Medic | Точные навыки: не подтверждено. |
| Pyro | Точные навыки: не подтверждено. |
| Mechanic | Точные навыки: не подтверждено. |
| Ranger | Девятый выживший; открывается на Survival Level 175. |

## Прогресс версии 1.0

| Система | Подтверждённая информация |
| --- | --- |
| Отряд | Один стартовый персонаж и до двух спасённых через SOS. |
| Навыки | Добавлены деревья навыков пятого ранга. |
| Синергии | Добавлены межперсонажные синергии. |
| Лагерь | Добавлены Survivors' Camp, миссии и Friendship. |
| Bio Lab | Открывается после Dead Terminal на Default. |
| Boss Rush | Открывается после Hardcore для каждой карты. |

## Частые вопросы

### Сколько выживших доступно?

Исследование версии 1.0 подтверждает девять персонажей.

### Как открыть Ranger?

В заметках разработчика указан Survival Level 175.
