This Yet Another Zombie Survivors upgrade guide separates three systems that share the word “upgrade”: choices made during a run, permanent general Training, and Survivor-specific skill trees. Decide which system is blocking progress before spending resources. Version 1.0 also adds Rank 5 and new team-related nodes, so Early Access upgrade limits cannot be treated as current.

Use the [weapon upgrade guide](/weapons/upgrades/) for weapon branches, the [Skill Tree guide](/guides/skill-tree/) for Survivor-specific progression, and the [General Points build](/builds/general-points-build-1-0/) for account-wide allocation. These pages answer separate upgrade questions. Keeping them separate prevents one system's advice from being applied to another.

## Separate Run and Permanent Upgrades

The [official game site](https://yazs.awesomegamesstudio.com/) describes choosing perks, abilities, items, and synergies during a run. Those choices shape the active squad until that run ends. Permanent progression is handled outside the run and affects later attempts.

Do not combine temporary level-up choices and permanent points into one table. A strong temporary weapon choice cannot replace an account unlock, while a permanent bonus does not guarantee a particular item will appear. Exact interactions not shown in current source material are **unconfirmed**.

## Understand General Training

The maintained [wiki upgrades page](https://yetanotherzombie.wiki.gg/wiki/Upgrades) describes Training as permanent progress purchased with Training Points. It connects those points to money collected during runs and some achievement rewards. Because the page may include Early Access information, current names and numerical costs should be checked in the live menu.

General upgrades apply broadly rather than defining one Survivor's complete kit. Spend toward the problem that repeatedly ends runs, such as insufficient damage, survival, movement, or resource collection. A universal best first upgrade is **unconfirmed** by official evidence.

## Use Free Respecs to Test Priorities

The live [Steam achievement list](https://steamcommunity.com/stats/2163330/achievements/) includes **Forget It**, whose condition involves resetting points spent in a skill tree and explicitly notes free respecs. That is independent evidence that experimentation does not permanently lock every choice. Check the current interface before resetting so the affected tree is clear.

Use a respec to compare one focused change at a time. Keep the arena, mode, squad, and main build similar so the result is interpretable. Exact performance gains from any point allocation are **unconfirmed** without controlled measurements.

## Account for Rank 5 in Version 1.0

The developer's [version 1.0 release notes](https://awesomegamesstudio.com/blog/yazs-full-release/) add Rank 5 to every Survivor skill tree. Each Survivor receives two new synergy nodes, two passive-improvement nodes, and one passive that benefits the team while that Survivor is present. This makes current squad progression deeper than an older four-rank explanation.

An Early Access video can still show the menu structure or the idea of prioritization. It cannot prove the current cap, final node names, or present balance. Any specific Rank 5 value absent from the current game or official notes is **unconfirmed**.

## Treat Weapons and Abilities as Different Paths

Run-level weapon and ability choices can support different item effects and synergies. A weapon-focused squad should not automatically take every ability option, and an ability-focused squad may value cooldown and trigger interactions differently. The collected official material confirms flexible combinations but not one global best path.

Identify the squad's main damage or control source, then favor upgrades that reinforce it. If the build is failing against crowds or bosses, record which part is weak before changing direction. Exact damage formulas and universal breakpoints are **unconfirmed** here.

## Use Character Unlocks as Version Checks

The 1.0 release notes confirm Ranger as the ninth Survivor and set the unlock at Survival Level 175. Ranger's presence is an immediate check that a guide covers the full release rather than an older roster. A source omitting Ranger may still describe stable basics, but its progression limits need review.

The same caution applies to older character Rank achievements and weapon routes. Verify the node and unlock text in the current Survivor tree. Do not infer a current requirement solely from a pre-1.0 screenshot.

## Improve the Actual Failure Point

If enemies survive too long, test a more focused output allocation. If contact damage ends runs, compare health, mitigation, recovery, movement, or crowd-control options that are actually available. If progression is slow, examine resource-related choices without claiming that they outperform immediate survival in every mode.

Change one category, run the same goal again, and record the result. This produces useful evidence for the account's current state. A recommendation based on one different map, squad, and difficulty is **unconfirmed** as a universal rule.

## Connect Skill Trees to Team Synergies

Version 1.0 gives each Survivor cross-Survivor synergies and team-wide passive progression. That means a point can matter because of another squad member, not only because of the selected character's personal output. Check the required teammate and node before designing the run.

A synergy node does nothing if its prerequisite character or ability never enters the build. Plan the leader and likely recruits together, then inspect what is unlocked. Exact proc rates and best trio rankings are **unconfirmed** unless verified in the current skill tree and gameplay.

## Treat Old Numerical Advice as Historical

A [2023 beginner video](https://www.youtube.com/watch?v=825n_y5IQ7o) shows Training Points, tier gates, Leader perks, and the author's preference for early Endurance and Strength. It is useful evidence of the former interface and a player's reasoning. Its costs, values, and upgrade cap predate the full release.

Do not copy its point totals into a 1.0 table. Use it to identify questions to check in the current client, such as how tiers unlock and what a respec changes. Any unverified numerical carryover is **unconfirmed**.

## Build a Safe Upgrade Order

Start by naming the next goal: first clear, resource farming, a map unlock, a boss, or a restricted achievement. Choose a small set of permanent upgrades that address the failure point, then align run-level weapons, abilities, and items with the same plan. Reassess after the result rather than following a rigid list indefinitely.

This process is evidence-based without pretending one allocation works for every account. Save screenshots of current node descriptions when exact values matter. If a number, name, or prerequisite is absent from the collected material, label it **unconfirmed**.
