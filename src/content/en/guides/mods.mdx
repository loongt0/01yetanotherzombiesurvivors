The documented Windows path is `C:\Program Files (x86)\Steam\userdata\YOUR_STEAM_ID\2163330\remote\`. Copy the complete `remote` folder to a separate location before installing a framework or plugin. A custom Steam installation can use a different root path.

The developer also identifies `%AppData%\..\LocalLow\Awesome Games Studio\Yet Another Zombie Survivors\Saves\` for additional local backups. Copy that folder when present and preserve both original sets. The game can keep up to five backups per save slot, so repeated restarts after a problem may overwrite older recovery points.
