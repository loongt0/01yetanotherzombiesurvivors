## Choosing a class

Each Farever class offers a different way to explore the world.

- Choose a class that matches your preferred role.
- Try every class before committing to a build.

| Class | Role | Playstyle |
| --- | --- | --- |
| Guardian | Defense | Protect allies on the front line. |
| Ranger | Damage | Attack from a safe distance. |

Read the [Farever best class guide](/guides/farever-best-class) for a quick recommendation.
