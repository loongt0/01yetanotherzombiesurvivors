## The 4 classes

Classes determine your **baseline stats, armour type and identity**. Unlike a traditional MMO, switching weapons completely changes which active skills you have access to, so each class plays multiple roles in practice.

| Class | Role | Summary |
| --- | --- | --- |
| **Warrior** | Frontline / Tank-DPS | Plate-armoured bruiser with strong stagger and self-sustain. The most forgiving class to learn. |
| **Ranger** | Ranged DPS / Kite | Bows, traps and pets. Excellent solo class thanks to high mobility and burst at range. |
| **Mage** | AoE / Burst Caster | Elemental nuker. Squishy but melts grouped enemies; the highest damage ceiling in the game. |
| **Mystic** | Support / Hybrid | Buff/heal flex with battle-magic. Best in co-op groups but workable solo with the right weapon. |

## The 6 jobs

Jobs are **crafting and gathering professions** that run parallel to your class. You can level all 6 on a single character, but most players focus 2–3 to maximise efficiency.

| Job | What it does |
| --- | --- |
| **Blacksmith** | Forges and upgrades weapons; required to push gear past tier 3. |
| **Alchemist** | Brews combat potions, food and the powerful long-duration buffs. |
| **Hunter** | Tracks and skins beasts for crafting leathers, plus rare meat ingredients. |
| **Miner** | Gathers ores and crystals — gates progression for armour smithing. |
| **Scholar** | Researches and inscribes runes, the main way to add stats to gear. |
| **Cook** | Combines ingredients into stronger food buffs than the alchemist's base set. |

## Best class combos for co-op

- **Duo:** Warrior + Mage — classic frontline + burst.
- **Trio:** Warrior + Mystic + Ranger — sustainable, scales well into dungeons.
- **Solo:** Ranger or Warrior — both can self-sustain through every EA dungeon.

## Should you respec?

Respec is cheap. Because weapons drive your skill kit, you rarely need a full class respec — just swap the weapon. Save respec scrolls for end-game stat re-allocation.

## Class deep-dives

### Warrior — best for new players

The most forgiving class. Plate armour, the highest base HP, and a stagger-focused kit that punishes greedy bosses. Pair Greatsword (single-target) with Sword & Shield (panic block). Solo viability: 8/10. Group viability: 9.5/10. See [Stagger Warrior](/builds/) for the meta build.

### Ranger — best for solo players

The smoothest solo experience in Farever. Pet tank holds aggro, longbow keeps you safe, traps cover panic moments. Solo viability: 9.5/10. Group viability: 7/10 (lower stagger contribution). The S-tier solo build is [Pet Sniper Ranger](/builds/).

### Mage — highest damage ceiling

The fastest boss-killer in groups, but fragile early levels make solo Mage rough. Best in trios with Warrior + Mystic. Solo viability: 6.5/10. Group viability: 9/10. See [Burst Mage](/builds/).

### Mystic — flex support

The most flexible class. Tome heals + buffs, spear flexes into front-line damage when the tank is overwhelmed. Solo viability: 7/10. Group viability: 9/10. The required class for hard mode 4-stack. See [Battle Mystic + Tank Mystic](/builds/).

## FAQ — Farever classes

### How many classes are in Farever?

Four — Warrior, Ranger, Mage and Mystic. Class is fixed at character creation but every class can wield multiple weapon types, so each class plays multiple roles in practice.

### Best Farever class for beginners?

Warrior — highest base HP, most forgiving combat. Ranger is a close second thanks to pet tank + ranged kit. Avoid Mage as your first class; the early levels are punishing.

### Best Farever class for solo play?

Ranger (9.5/10 solo). Pet tank handles aggro while you snipe from range. Warrior is the second-best solo class.

### Best Farever class for co-op / groups?

Warrior tank + Mystic support + Mage DPS is the trio meta. Add a Ranger as the 4th for hard mode utility.

### Can I switch classes in Farever?

No — class is locked at character creation. But you can switch weapon families freely, and each weapon retrains your skills GW2-style. Most "respec" needs are solved by changing weapons.

### How does the talent tree work?

Each class has 3 talent trees with 40 points to fully fill one. Talent respec is cheap (50–500 gold). Stat respec is more expensive (1000 gold flat) and only available in the Autumn capital.
